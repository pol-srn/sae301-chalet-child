# Le Chalet : thème enfant Storefront

Thème enfant WordPress / WooCommerce pour le click & collect du restaurant Le Chalet (Limoges).
Projet réalisé dans le cadre de la SAé 3.01 (BUT MMI).

- Thème parent : Storefront
- Extensions : WooCommerce, Secure Custom Fields, Classic Editor
- Les commits sont préfixés par l'itération : `[IT-X]`
